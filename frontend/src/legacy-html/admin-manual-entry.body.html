السجل اليومي لكل مرحلة (Stage)

سجّل موظف واحد في تاريخ واحد، أو املا جدول لعدة موظفين مرة واحدة.

اختر الشيفت/القسم (اختياري) لتصفية عدد الموظفين الظاهرين في الجدول، ثم اضغط "بناء الجدول".

الملخص الشهري للموظف

تارجت الإشراف (OPP A / OPP B / QC / File Trail)
